# Bincom Test – HTML, CSS, PHP (PDO/MySQL)
1. Import bincom_test.sql into MySQL (database name: bincom_test).
2. Edit config.php (or set DB_HOST, DB_NAME, DB_USER, DB_PASS env vars).
3. Run locally: `php -S localhost:8000` in this folder, then open http://localhost:8000
   Or upload the folder to any PHP host (e.g. InfinityFree) and import the SQL via phpMyAdmin.
Pages: q1.php (polling unit result), q2.php (LGA summed result), q3.php (add new polling unit).
